# Sicherheitsmeldungen

Bitte keine Zugangsdaten, Dokumente, Bankdaten oder Angaben echter Mietparteien in öffentlichen Issues veröffentlichen.

Sicherheitsrelevante Fehler vertraulich über GitHubs private Sicherheitsmeldung melden, sofern diese für das Repository aktiviert ist. Andernfalls zunächst ohne technische Angriffsdaten um einen vertraulichen Kontaktweg bitten.

Vor Produktiveinsatz und nach Updates eine getrennte Testinstallation verwenden. Die Anwendung kontrolliert Datensatzbesitz und Downloads auf dem Server. Ein unabhängiges Sicherheitsgutachten oder eine rechtliche Zertifizierung ist mit dieser Veröffentlichung nicht verbunden.
